# 🤖 Building-ChatBots

Welcome to **Building-ChatBots** — a fun and educational project where I experiment with building simple, interactive chatbots using Python and machine learning concepts! 🧠💬

---

## 🛠️ What's Inside

This repository contains a collection of mini chatbot projects:
- **CoffeeBot**: A basic chatbot to take coffee orders ☕
- **Discover Insights into Classic Texts**: An exploration of NLP techniques to uncover hidden patterns in famous books 📚
- **Mystery Friend**: A guessing game chatbot with a fun personality 🎭

Each project demonstrates key ideas behind conversational AI, from simple pattern matching to basic natural language processing techniques.

## 🚀 How to Run

1. Clone this repo:
   ```bash
   git clone https://github.com/pyPrarthan/Building-ChatBots.git
   cd Building-ChatBots
   ```

2. Navigate to a project folder (e.g., `CoffeeBot`) and run the script:
   ```bash
   python coffeebot.py
   ```

   *(Make sure you have Python 3 installed!)*
